# نظام إدارة العلاوات والترفيعات (ALAWAT) 🏢

نظام سحابي متكامل لإدارة بيانات الموظفين، العناوين والدرجات الوظيفية، وأرشفة سجل العلاوات السنوية والترفيعات مع التحديث الآلي لرواتب الموظفين.

تم بناء النظام بالكامل باستخدام:
- **React 18** (Vite)
- **Tailwind CSS** مع دعم كامل للاتجاه من اليمين لليسار (RTL) وخط **Cairo**
- **React Router v6**
- **Supabase** (قاعدة بيانات PostgreSQL سحابية + سياسات أمان RLS)
- **Lucide React** للأيقونات العصرية

---

## 🚀 المميزات الرئيسية

1. **صفحة بيانات الموظفين (Employees Page):**
   - جدول تفاعلي ببيانات الموظف (الاسم، العنوان الوظيفي، الدرجة، تاريخ التعيين، الراتب الحالي، القسم، الهاتف).
   - نموذج إضافة موظف جديد ونموذج تعديل البيانات.
   - حذف الموظف مع نافذة تأكيد آمنة.
   - شريط بحث فوري وفلترة حسب العنوان الوظيفي.
   - زر مباشر لمنح علاوة أو ترفيع للموظف من جدول الموظفين مباشرة.
   - بطاقات إحصائيات لكادر الموظفين وكتلة الرواتب ومتوسط الراتب.
   - تصدير بيانات الموظفين إلى ملف CSV / Excel.

2. **صفحة العناوين والدرجات الوظيفية (Job Titles Page):**
   - جدول العناوين الوظيفية والدرجة وسلم الرواتب ومقدار العلاوة السنوية المقررة.
   - حساب عدد الموظفين الفعليين المرتبطين بكل عنوان وظيفي.
   - إضافة عنوان وظيفي جديد وتعديل العناوين الحالية.
   - حماية ضد حذف العناوين المرتبطة بموظفين فعليين.

3. **صفحة سجل العلاوات والترفيعات (Allowances & Promotions History):**
   - أرشفة كاملة لكل قرارات العلاوات والترفيعات.
   - وسوم بصرية مخصصة للتمييز بين (علاوة سنوية) و(ترفيع وظيفي).
   - توثيق الراتب السابق والجديد ومقدار الزيادة ورقم الأمر الإداري وتاريخ السريان.
   - **تحديث الراتب تلقائياً:** فور تسجيل استحقاق للموظف، يتم تحديث حقل `الراتب الحالي` (والعنوان الوظيفي في حالة الترفيع) في جدول الموظفين آلياً وبشكل لحظي.

## 🛠️ خطوات ربط Supabase

### 1. إنشاء الجداول في Supabase
1. سجل الدخول إلى [Supabase](https://supabase.com) وأنشئ مشروعاً جديداً.
2. ادخل إلى قسم **SQL Editor** في لوحة تحكم Supabase.
3. انسخ محتوى الملف المرفق [supabase-schema.sql](file:///c:/Projects/ALAWAT/supabase-schema.sql) بالكامل والصقه في المحرر ثم اضغط **RUN**.

### 2. وضع مفاتيح الربط في المشروع
قم بإنشاء ملف `.env` في المجلد الرئيسي للمشروع (أو عدل الملف الحالي) وضع القيم الخاصة بمشروعك:

```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
```

> **ملاحظة:** يعمل النظام تلقائياً بوضع المعاينة المحلي (Local Mode) في حال لم يتم إدخال مفاتيح Supabase بعد، مما يتيح لك تجربة النظام واختباره بالكامل فوراً.
